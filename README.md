# 스마트 금융 계산기 & 마이페이지 (dmu_ai)

예금·적금·대출을 **세후 실수령액** 기준으로 간편하게 계산하고, 조건별로 비교하며, 결과를 저장할 수 있는 모바일 웹 애플리케이션입니다.  
수업 팀 프로젝트(AI디어)로 개발되었습니다.

| 항목 | 내용 |
| --- | --- |
| 현재 버전 | **0.9** (`index.html` 기준, 프로토타입 폴더 `prototyping_week11_ver0.9.html`에 해당) |
| 화면 형태 | 모바일 폭(최대 448px) 웹 화면 |
| 기술 스택 | HTML, Tailwind CSS(CDN), Font Awesome(CDN), JavaScript |
| 저장 방식 | 브라우저 LocalStorage 기반 데모 저장 (v0.9 기준) |
| 문서 갱신일 | 2026-11-24 |

   │  ├─ wireframe_week10_ver0.1.html ~ ver0.5.html (ver0.3은 _01, _02 두 파일)

## 실행 및 배포 방법

### 로컬 실행 방법
1. 이 저장소를 로컬 환경에 내려받습니다(Clone 또는 ZIP 다운로드).
2. `index.html` 파일을 웹 브라우저로 엽니다.
3. Tailwind CSS와 Font Awesome을 CDN으로 불러오므로 **인터넷 연결**이 필요합니다.

### GitHub Pages 배포 방법
1. 이 저장소의 파일들을 GitHub Repository에 업로드합니다.
2. Repository의 **Settings > Pages** 메뉴로 이동합니다.
3. **Source**에서 `Deploy from a branch`를 선택하고 `main` 브랜치의 `/ (root)` 폴더를 지정한 뒤 저장(Save)합니다.

## 1-1. 와이어프레임 폴더 (오름차순)

### v0.1 — `wireframe_week10_ver0.1.html` (최초 버전)

화면 한 장짜리 모바일 계산기 시안입니다.

- 서비스 이름은 "내 금융 계산기"이며, 데스크톱에서는 "모바일 폭에서 확인해 주세요"라는 안내가 나오도록 설계했습니다.
- 계산 유형은 **예·적금 / 대출** 두 가지로 나눴습니다.
- 입력 항목은 예치 원금, 월 납입액(적금 선택 시 참고), 연 이율, 기간입니다.
  - 기간: 6개월·1년·2년·3년·5년·10년 중 선택하는 칩 방식
  - 이자 계산 방식: 단리 / 연 복리 중 선택
  - 이자 과세: 일반 과세 15.4% / 비과세 0% / 저율 과세 1.4% 중 선택
- 결과 영역에는 예상 만기 금액, 예치 원금, 세전 이자(350,000원), 예상 세금(53,900원), 세후 이자(296,100원)를 표시합니다.
- "금액 변화 미리보기" 개념 그래프(시작 → 기간 경과 → 만기)가 포함되어 있으나 실제 계산값을 반영하지는 않습니다.
- 하단 탭: 계산기 / 비교하기 / 이용 안내
- *참고 메모*: 예시 만기 금액이 10,295,300원으로 적혀 있어, 원금 + 세후 이자(10,296,100원)와 800원 차이가 납니다.

## 1-3. 프로토타입 폴더 변경 이력 (v0.1 → v0.9, 오름차순)

아래 이력은 `pages/prototyping/`에 보관된 실제 HTML 파일을 버전별로 비교해 정리했습니다. 각 버전은 바로 앞 버전과 비교했으며, 기능 추가뿐 아니라 화면·문구·계산 로직·저장 구조의 변경 및 제거 사항도 함께 기록했습니다. `index.html`은 현재 프로토타입 v0.9를 기준으로 별도 파일(`js/app.js`, `css/style.css`)로 기능과 스타일을 분리한 구현본입니다.

4. **조건 비교 및 기록**
   - 금리·기간 조건 A와 B를 비교하는 화면과 계산 결과를 저장하고 확인하는 기록 화면을 마련했습니다.

### v0.8 — `prototyping_week12_ver0.8.html`

   - 이전 버전의 브라우저 내부 저장 중심 흐름에서 Google Apps Script Web App을 경유해 Google Sheets에 계산 기록을 추가하는 방식으로 바뀌었습니다.
   - 저장 요청 중 버튼 문구를 `구글 시트에 저장 중...`으로 표시하고, 저장 성공·실패에 대한 토스트 메시지를 제공하도록 변경했습니다.
2. **회원가입 데이터의 Google Sheets 연동**
   - 회원가입 시 `users` 시트 데이터를 조회해 동일 이메일이 이미 존재하는지 확인합니다.
   - 중복 이메일이면 가입을 중단하고 로그인 화면으로 전환하며 해당 이메일을 로그인 입력란에 채웁니다.
   - 중복이 아니면 이름·이메일·비밀번호를 `users` 시트에 행으로 추가합니다.
3. **로그인 검증 방식 변경**
   - 로그인 시 `users` 시트의 회원 데이터를 불러와 이메일 계정을 찾고, 해당 계정의 비밀번호와 입력값을 비교합니다.
   - 가입·로그인 성공 시 현재 사용자 이름과 이메일을 `fin_calc_user` 키로 브라우저 LocalStorage에 저장해 로그인 상태를 유지합니다.
   - 로그아웃 시 해당 세션 정보를 LocalStorage에서 제거합니다.
4. **계산 기록 조회 및 화면 개편**
   - 마이페이지의 기록 제목을 `저장된 계산 결과 목록`에서 `구글 시트 저장 기록 목록`으로 변경했습니다.
   - `전체 삭제` 중심 UI 대신 `새로고침` 버튼을 제공해 Google Sheets의 최신 기록을 다시 불러오도록 변경했습니다.
   - `history` 시트에서 기록을 조회한 뒤 현재 로그인한 사용자의 이메일과 일치하는 행만 화면에 표시하고, 목록을 최신 기록 우선으로 정렬합니다.
   - 기록 항목에는 계산 유형, 저장 날짜, 결과 금액 및 입력 조건 요약을 표시합니다.

## 2.4 정보 구조(IA) 및 사용자 흐름

### 화면 구조
```
홈 ─┬─ 저축 계산 (예금 탭 / 적금 탭)
    ├─ 대출 계산
    └─ 마이페이지 ─┬─ 내 계산 기록
                   └─ 조건 실시간 비교
(공통) 로그인 / 회원가입 창, 개인정보 처리방침 창
(공통) 하단 내비게이션 탭: 홈 / 저축 / 대출 / 마이페이지
```

### 주요 사용 흐름
1. **계산 및 저장하기**: 홈에서 계산 유형(저축 또는 대출) 선택 → 금액·기간·이자율 입력 → `계산하기` 클릭 후 결과 확인 → 로그인(또는 회원가입) → `이 결과 구글 시트에 저장하기` 클릭 → 브라우저 저장소에 저장 → 마이페이지에서 기록 조회
2. **조건 비교하기**: 로그인 → 마이페이지 `조건 실시간 비교` 탭 이동 → 조건 A~E의 금액과 금리 입력 → `실시간 비교 결과 계산` 클릭 → 세후 이자 막대 그래프 및 유불리 금액 차이 확인

## 2.9 데이터 출처 및 면책 조항

이 애플리케이션은 **실제 은행·금융기관의 상품 정보나 실시간 금리 API를 연동하지 않습니다.** v0.8에서 Google Sheets는 회원 및 계산 기록을 저장하는 용도이며, 금융상품 데이터의 출처가 아닙니다.

| 데이터 구분 | 출처 | 비고 |
| --- | --- | --- |
| 예금·적금·대출 초기 입력값 | `index.html` 입력 필드에 설정된 팀 제작 예시값 | 예금 1,000만원, 적금 월 30만원, 대출 2,000만원 등. 실제 금융상품 조건이 아님 |
| 계산 결과 | `js/app.js`에 구현된 JavaScript 계산식 | 사용자가 입력한 금액·기간·금리를 바탕으로 브라우저에서 계산 |
| 이자 과세율 15.4% | `js/app.js`의 고정 상수 `0.154` | 일반과세 가정값. 사용자별 세금·상품별 과세 조건 조회 기능 없음 |

### 저장 구조 참고 (v0.9)

- 연동 방식: `js/app.js`에 설정된 Google Apps Script Web App URL로 `fetch` 요청
- 사용 시트 탭: `users` (회원 계정), `history` (계산 기록)
- 조회: GET 요청으로 시트별 데이터를 읽어옴
- 저장: POST 요청으로 회원 또는 계산 기록 행을 추가
- 저장소 역할 구분: Google Sheets는 회원 및 계산 기록 저장소이며, 예금·적금·대출 금리나 금융상품 원천 데이터를 제공하지 않음
- 실제 배포 시 Apps Script 배포 권한, 시트 접근 권한, 비밀번호 저장·전송 보안 설정을 별도로 점검해야 함

> **면책 안내**: 본 도구의 계산 결과는 단순 참고용입니다. 실제 금융기관의 우대금리, 세금 공제 조건, 중도상환수수료, 상품별 이자 계산 방식 및 실제 대출 실행일의 날짜 계산 방식에 따라 실제 수령액·상환액과 차이가 발생할 수 있습니다. 예금자보호제도 등 제도 안내도 실제 금융 의사결정 전 예금보험공사 및 관계 기관의 최신 공식 자료로 확인해야 합니다.
