# 금융 계산 웹 도구 (dmu_ai)

예금·적금·대출을 **세후 수령액** 기준으로 계산하고, 두 조건을 비교하고, 결과를 저장하는 모바일 웹 도구입니다.
수업 팀 프로젝트(AI디어)로 만들고 있습니다.

| 항목 | 내용 |
| --- | --- |
| 현재 버전 | **0.6** (`index.html` 기준, 와이어프레임 폴더 `wireframe_week11_ver0.6.html`과 같은 버전) |
| 화면 형태 | 모바일 폭(최대 448px) 웹 화면 |
| 기술 | HTML, Tailwind CSS(CDN), Font Awesome(CDN), JavaScript |
| 저장 방식 | 브라우저 LocalStorage (서버 없음) |
| 문서 갱신일 | 2026-11-17 |

## 목차

1. [변경 이력](#1-변경-이력)
2. [PRD](#2-prd)

## 폴더 구조

```
dmu_ai/
├─ index.html                  # 현재 서비스 화면 (v0.6)
├─ css/
│  └─ style.css                # 스크롤바 숨김, 화면 전환 효과
├─ js/
│  ├─ tailwind-config.js       # Tailwind 색상(brand)·글꼴 설정
│  ├─ app.js                   # index.html에서 쓰는 계산·로그인·기록 코드
│  └─ main.js                  # 이전 프로토타입용으로 보이는 스크립트 (index.html에서는 불러오지 않음)
└─ pages/
   ├─ wireframe/               # 화면 설계(와이어프레임) 버전 모음
   │  ├─ wireframe_week10_ver0.1.html ~ ver0.5.html (ver0.3은 _01, _02 두 파일)
   │  └─ wireframe_week11_ver0.6.html
   └─ prototyping/             # 동작하는 프로토타입 버전 모음
      ├─ prototyping_week10_ver0.1.html
      └─ prototyping_week11_ver0.2.html ~ ver0.6.html
```

## 실행 방법

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저로 엽니다.
3. Tailwind와 Font Awesome을 CDN으로 불러오므로 인터넷 연결이 필요합니다.

# 1. 변경 이력

- 버전 번호는 **와이어프레임 폴더 기준**입니다. (0.1 → 0.6)
- 오름차순(오래된 버전 → 최신 버전)으로 씁니다.
- 각 버전에는 **바로 이전 버전과 달라진 점**을 적었습니다.
- 파일 이름의 `week10`, `week11`은 작업 주차입니다. 정확한 날짜는 저장소에 없어서 적지 않았습니다.
- 맨 아래에는 참고용으로 프로토타입 폴더의 변경 이력도 정리했습니다.

### v0.1 — `wireframe_week10_ver0.1.html` (최초 버전)

화면 한 장짜리 모바일 계산기 시안입니다.

- 이름은 "내 금융 계산기"입니다. 데스크톱에서는 "모바일 폭에서 확인해 주세요"라는 안내가 나오도록 설계했습니다.
- 계산 유형은 **예·적금 / 대출** 두 가지로 나눴습니다.
- 입력 항목은 예치 원금, 월 납입액(적금 선택 시 참고), 연 이율, 기간입니다.
  - 기간은 6개월·1년·2년·3년·5년·10년 중에서 고르는 칩 방식입니다.
  - 이자 계산 방식은 단리 / 연 복리 중에서 고릅니다.
  - 이자 과세는 일반 과세 15.4% / 비과세 0% / 저율 과세 1.4% 중에서 고릅니다.
- 결과 영역에는 예상 만기 금액, 예치 원금, 세전 이자(350,000원), 예상 세금(53,900원), 세후 이자(296,100원)를 보여줍니다.
- "금액 변화 미리보기"라는 개념 그래프(시작 → 기간 경과 → 만기)가 있습니다. 실제 계산값을 반영한 그래프는 아닙니다.
- 아래 탭은 계산기 / 비교하기 / 이용 안내입니다.
- 예시 숫자 메모: 만기 금액이 10,295,300원으로 적혀 있습니다. 원금 + 세후 이자(10,296,100원)와 800원 차이가 납니다.

## 2.4 구조·사용 순서

**화면 구조**

```
홈 ─┬─ 저축 계산 (예금 탭 / 적금 탭)
    ├─ 대출 계산
    └─ 마이페이지 ─┬─ 내 계산 기록
                   └─ 조건 실시간 비교
(공통) 로그인 / 회원가입 창, 개인정보 처리방침 창
(공통) 아래 탭: 홈 / 저축 / 대출 / 마이페이지
```

**사용 순서 (계산하고 저장하기)**

1. 홈에서 계산 종류(저축 또는 대출)를 고릅니다.
2. 금액, 기간, 연 이자율을 입력합니다. (대출은 상환 방식 선택 칸도 있음)
3. "계산하기" 버튼을 누르면 결과 카드가 나옵니다.
4. 저장하려면 로그인합니다. 계정이 없으면 회원가입을 합니다.
5. "이 결과 마이페이지에 저장하기"를 누릅니다.
6. 마이페이지의 "내 계산 기록"에서 최신순으로 확인합니다.

**사용 순서 (조건 비교하기)**

1. 로그인합니다.
2. 마이페이지에서 "조건 실시간 비교" 탭을 엽니다.
3. 조건 A, B의 금액과 금리를 입력하고 "실시간 비교 결과 계산"을 누릅니다.
4. 세후 이자 막대 그래프와 차이 문구를 확인합니다.

## 2.5 기능 설명

| ID | 기능 | 설명 | 계산식 / 규칙 | 상태 |
| --- | --- | --- | --- | --- |
| F-01 | 홈 | 계산 종류 선택, 최근 저장한 계산 보기. 비로그인이면 샘플 카드와 로그인 안내를 보여줌 | - | 구현됨 |
| F-02 | 예금 계산 | 예치 금액, 예치 기간(개월), 연 이자율 입력 → 세전 이자, 이자 과세(15.4%), 세후 예상 수령액 | 세전 이자 = 금액 × 연이율 × (개월 ÷ 12) / 세금 = 세전 이자 × 0.154 | 구현됨 (단리·15.4% 고정) |
| F-03 | 적금 계산 | 월 납입 금액, 저축 기간, 연 이자율 입력 → 총 원금, 세후 이자, 세후 예상 수령액 | 세전 이자 = 월 납입액 × (연이율 ÷ 12) × n(n+1)/2 (n = 개월 수) / 세금 15.4% | 구현됨 (단리·15.4% 고정) |
| F-04 | 대출 계산 | 대출 금액, 기간, 연 이자율 입력 → 월 평균 상환액, 대출 원금, 총 이자 | 원리금균등상환 공식 | 일부 구현 (아래 2.7 참고) |
| F-05 | 결과 저장 | 계산 결과를 마이페이지 기록에 저장 | 날짜는 저장한 날 기준 | 구현됨 |
| F-06 | 내 계산 기록 | 저장한 계산을 최신순으로 보여주고 "전체 삭제" 제공 | - | 구현됨 |
| F-07 | 조건 실시간 비교 | 예금 조건 A, B 입력 → 세후 이자 막대 그래프와 차이 문구 | 세후 이자 = 금액 × 연이율 × (1 − 0.154) | 일부 구현 (아래 2.7 참고) |
| F-08 | 회원가입 / 로그인 | 닉네임, 이메일, 비밀번호로 가입·로그인. 로그인 전에는 기록·비교 사용 불가 | 브라우저 LocalStorage에서 확인 | 구현됨 (데모) |
| F-09 | 개인정보 처리방침 | 수집 항목, 이용 목적, 파기, 계산 오차 책임 한계 안내 | - | 구현됨 |

**기능 흐름 테스트**

- 비로그인 상태에서 마이페이지를 열면 잠금 안내가 나온다.

- 계산 후 "저장하기"를 누르면 마이페이지 기록 맨 위에 생긴다.
- "전체 삭제"를 누르면 기록이 비워진다.
- 로그아웃하면 다시 비로그인 화면이 된다.
